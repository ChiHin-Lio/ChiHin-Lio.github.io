私隱政策及免責聲明

最後更新：2026 年 9 月 30 日 · 適用於澳泊 Parking Go iOS 及 Android 應用程式

澳泊 Parking Go（「本應用程式」）尊重您的私隱。本政策說明您使用停車場、巴士、輕軌、交通地圖及路線查詢服務時，可能涉及的資料及第三方服務。

1. 我們處理的資料

  • 位置及路線查詢：在您授權後，裝置位置用於附近停車場、附近站點、地圖定位及站對站規劃。查詢可能將座標、起終點或搜尋文字傳送至提供相關服務的伺服器或地圖服務。您可在裝置設定中撤回位置權限。
  • 帳戶及收藏：如您登入或建立帳戶，我們會處理電郵、認證識別資料，以及您選擇同步的收藏或設定。未登入時可使用的功能不要求您建立帳戶。
  • 通知：如您啟用通知，推送服務可能處理裝置推送 token 及相關通知設定。
  • 語音查詢：您主動啟用語音查詢並授權後，系統語音辨識服務會處理聲音及辨識結果。實際處理可在裝置或語音服務供應商的伺服器進行，視乎平台及設定。本應用程式使用辨識文字進行查詢，並不提供錄音儲存功能。
  • 會員及付款：如您使用會員服務，我們會處理驗證會員資格所需的訂閱狀態及交易識別資料。付款由相應平台或付款服務處理；本應用程式不儲存您的銀行卡資料。乘車碼入口只記住您選擇的支付服務，不讀取支付帳戶、銀行卡或乘車碼內容。
  • 技術及服務資料：伺服器及第三方 SDK 可能處理 IP 位址、裝置及應用程式資訊、錯誤、請求時間及服務互動資料，用於提供服務、安全防護及故障處理。

2. 資料用途及巴士預測

資料用於提供查詢、定位、路線規劃、帳戶認證、收藏同步、會員驗證及您選擇的通知。巴士發車及到站預測使用交通來源的巴士位置、路線、歷史行程及路段時間資料；預測並不代表官方班次保證，亦不要求收集您的個人行程歷史。

3. 廣告

本應用程式使用 Google AdMob 顯示廣告，並以非個人化廣告設定提出請求。非個人化不代表完全沒有資料處理：Google Mobile Ads SDK 仍可能處理 IP 位址、裝置識別資料、廣告互動及診斷資料，以投放廣告、計算成效及防止濫用。實際處理受平台權限、您的選擇及 Google 政策影響。

詳情請參閱 Google 私隱政策及 個人化與非個人化廣告說明。

4. 第三方服務及資料分享

我們不出售您的個人資料。提供功能所需的資料可能由以下服務處理：

  • Google Firebase：認證、雲端資料、推送通知及遠端設定。Firebase 私隱說明。
  • Apple 及系統語音服務：平台功能、登入、訂閱、通知或語音辨識。Apple 私隱政策。
  • Mapbox、OpenStreetMap 及地圖／導航服務：地圖載入、位置顯示、地址搜尋或您選擇開啟的導航。Mapbox SDK 亦可處理地圖使用及遙測資料；處理取決於平台及 SDK 設定。Mapbox 私隱政策、OpenStreetMap Foundation 私隱政策。外部 Google Maps／高德地圖適用其各自政策。
  • Railway 及相關雲端服務：提供本應用程式後端服務及所需的資料儲存。
  • GitHub Pages：託管本聲明頁面。瀏覽本頁時，GitHub 會為網站安全處理訪客 IP 位址等資料。GitHub 私隱聲明。

5. 安全及資料保留

我們使用安全通訊及適當存取控制保護資料。帳戶及同步資料按提供功能所需保留；技術記錄及第三方服務資料按相關用途與服務政策處理。沒有任何網絡傳輸或儲存方法能保證絕對安全。

6. 您的選擇及權利

  • 在裝置設定中管理位置、咪高峰及通知權限。
  • 選擇不使用登入、語音或收藏同步等可選功能。
  • 透過應用程式的帳戶刪除功能，或聯絡我們，提出查閱、更正或刪除帳戶及相關資料的要求。

7. 聯絡我們及政策更新

如有私隱疑問或資料處理要求，請聯絡：chi.lio@icloud.com。本政策如有更新，會在此頁刊載最新日期；重大變更會透過適當方式通知。

8. 交通資料及免責聲明

停車位、巴士位置／班次、輕軌轉乘、Road Network 路面情況及路線建議來自澳門交通事務局（DSAT）、公開交通資料及其他服務，僅供參考。本應用程式並非 DSAT 官方應用程式。

  • 即時資料及模型預測可能延遲、缺失或有誤，請以現場情況、官方公告及實際營運為準。
  • Road Network 不代表所有道路均有即時資料；沒有資料不表示道路暢通。
  • 巴士發車／到站預測及轉乘建議不是保證，請預留足夠時間。
  • 部分巴士資料來自 DSAT 網站公開資訊，並非官方對外 API；相關資料的權利屬其各自權利人。
  • 服務可能因維護、資料來源中斷或其他因素而暫停。在適用法律容許的範圍內，我們不對因依賴上述參考資料而造成的損失承擔責任。
